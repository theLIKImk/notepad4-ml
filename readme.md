# Notepad4-ML (Notepad4-MultiLabel)

**English** | [简体中文](readme_zh_cn.md)

![Notepad4-ML](docs/Notepad4-ml-bar.png)

Notepad4-ML is a multi-tab fork based on [Notepad4](https://github.com/zufuliu/notepad4),
adding tabs and scrollbar match markers to this originally single-document lightweight editor.

- **Version**: 0.2.1
- **Based on upstream**: Notepad4 v26.10 (r6392, 7b269f54)
- **Upstream baseline commit**: `3afea94b18c469b95b504553a5ece1a9e4c57d9e` (2026-10-23)

## New features in this fork

**Multiple tabs**
   - Top tab bar for multiple open files, showing file names and unsaved marker `*`
   - `Ctrl+Tab` / `Ctrl+Shift+Tab` to switch, `Ctrl+W` to close, `Ctrl+N` to create new
   - Each tab independently preserves content, undo history, cursor, scroll position, encoding, line endings, and read-only state
   - Drag a tab sideways to reorder it in the tab bar
   - Drag a tab out of the window and drop it onto another Notepad4-ML window to move it there (unsaved content included; the source tab is closed, no save prompt)
   - Toolbar: Close Current Tab, Open in New Window
   - This feature can be freely enabled/disabled

**Match markers on the vertical scrollbar**
   - When using "Mark All Matches" or "Find All", markers are drawn at line positions on the actual vertical scrollbar
   - Markers remain visible while scrolling
   - Color and opacity are configurable

## Before reporting an issue, first determine where it belongs

Before submitting an issue, **please first confirm whether the same problem also exists in upstream Notepad4. Upstream issues will not be handled**:

1. Download the latest official Notepad4 from <https://github.com/zufuliu/notepad4/releases>
2. Reproduce the issue using the same steps
3. Use the table below to determine where to submit it:

| Symptom | Where to submit |
| --- | --- |
| Reproducible in official Notepad4 (syntax highlighting, encoding, printing, lexing, etc.) | Upstream <https://github.com/zufuliu/notepad4/issues> |
| Only occurs in Notepad4-ML (tabs, scrollbar markers, new window-related) | This project's issues |
| Not sure | First state in this project's issue whether it reproduces in the official version |

Please include in the issue:

- Notepad4-ML version
- Windows version
- Reproduction steps
- Whether it has been reproduced in official Notepad4

## Download and usage

Releases provide 32/64-bit builds.

Supported languages: English, Simplified Chinese, Traditional Chinese, Japanese, Korean, German, French, Italian,
Polish, Portuguese (Brazil), Russian, Slovenian.

## Building from source

This fork is built with the zig + LLVM-MinGW toolchain (the scripts are not in this repository).
The original upstream build methods (MSVC / MinGW Makefile) are still available; see the
[upstream Wiki](https://github.com/zufuliu/notepad4/wiki/Build-Notepad4).

Upstream project dependencies: Scintilla 5.6.7, Lexilla 5.5.4, Boost.Regex 1.91.
